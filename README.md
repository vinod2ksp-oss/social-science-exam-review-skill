# 零基础社科期末｜三天速成 Agent Skill

> **考试只剩 3 天了，还没看过ppt怎么办。**

## 适用场景

- 零基础 / 基本没听课，距离期末考试只有 **72 小时左右**。
- 社会科学类课程：经济学、管理学、公共管理、社会学、政治学、教育学等。需依据实际课程资料确定范围。
- 考试包含名词解释、简答、论述、计算、证明、材料分析；
- 手头有教师 PPT、PDF、讲义、作业、考试范围或往年题，希望 AI **主动组织复习、闭卷提问、批改、查漏补缺**。

## 三天速成路线

| 天数 | 主要目标 | 交付内容 | 验收方式 |
|---|---|---|---|
| **Day 1 · 从 0 到懂** | 全书扫描、考点分级、核心概念入门 | 一页课程地图、优先级表、A 类考点初步笔记 | 10 分知识唤醒小测 |
| **Day 2 · 从懂到会答** | 补关键章节、建立跨章联系、训练题型 | 名词解释和简答骨架、材料题事实→理论映射 | 限时章节测＋材料题微练 |
| **Day 3 · 从会答到会考** | 模考、错题补弱、答题速度与精准性 | 模拟试卷、评分明细、薄弱点清单、考前 1 页速记 | 按实际题型限时模拟 |

默认按 **每天 6 小时有效学习（共 18 小时）** 设计。可以改成每天 3 小时、9 小时或给出不等时长；Agent 会重排内容，不会假装时间充足。

## 两种 Skill，可分别调用

| Skill | 适用情况 | 调用方法 |
|---|---|---|
| **零基础三天速成** | 考试迫近，需要抓住关键内容快速形成答题能力 | `$three-day-zero-base-exam` |
| **两轮递进式复习** | 有更充足时间，想逐节、逐章完整掌握 | `$two-pass-exam-review` |

## 直接使用

在已打开本仓库的 Codex（支持 Agent Skills 的环境）中输入：

```text
$three-day-zero-base-exam
我完全零基础，三天后考《产业经济学》，每天能学习6小时。
考试题型：名词解释、简答、材料题。
请先读取我提供的老师PDF，建立课程知识地图，生成三天冲刺计划，并立即开始Day 1的教学和闭卷小测。
```
