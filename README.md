# 零基础社科期末｜三天速成 Agent Skill

> **考前只剩 3 天？从看不懂课件，到能写出有逻辑的考试答案。**
>
> 一套以教师资料为依据、以真实考试题型为目标的互动式冲刺方法。不是“背了就一定能过”的保证，而是把有限时间集中在最值得学、最容易在答题中用上的知识上。

## 适用场景

- 零基础 / 基本没听课，距离期末考试只有 **72 小时左右**。
- 社会科学类课程：经济学、管理学、公共管理、社会学、政治学、教育学等。需依据实际课程资料确定范围。
- 考试包含名词解释、简答、论述、材料分析；如有选择、计算等，也按教师说明增设。
- 手头有教师 PPT、PDF、讲义、作业、考试范围或往年题，希望 AI **主动组织复习、闭卷提问、批改、查漏补缺**。

## 三天速成路线

| 天数 | 主要目标 | 交付内容 | 验收方式 |
|---|---|---|---|
| **Day 1 · 从 0 到懂** | 全书扫描、考点分级、核心概念入门 | 一页课程地图、优先级表、A 类考点初步笔记 | 10 分知识唤醒小测 |
| **Day 2 · 从懂到会答** | 补关键章节、建立跨章联系、训练题型 | 名词解释和简答骨架、材料题事实→理论映射 | 限时章节测＋材料题微练 |
| **Day 3 · 从会答到会考** | 模考、错题补弱、答题速度与精准性 | 模拟试卷、评分明细、薄弱点清单、考前 1 页速记 | 按实际题型限时模拟 |

默认按 **每天 6 小时有效学习（共 18 小时）** 设计。可以改成每天 3 小时、9 小时或给出不等时长；Agent 会重排内容，不会假装时间充足。

## 两种 Skill，可分别调用

| Skill | 适用情况 | 调用方法 |
|---|---|---|
| **零基础三天速成（新）** | 考试迫近，需要抓住关键内容快速形成答题能力 | `$three-day-zero-base-exam` |
| **两轮递进式复习（原版保留）** | 有更充足时间，想逐节、逐章完整掌握 | `$two-pass-exam-review` |

两者互不覆盖，可以先使用速成版，考后或有时间再切换深度版。原版历史进度文件保留在自身 `state/` 下，**不会被新 Skill 误判为其他课程的已掌握记录**。

## 直接使用

在已打开本仓库的 Codex（支持 Agent Skills 的环境）中输入：

```text
$three-day-zero-base-exam
我完全零基础，三天后考《产业经济学》，每天能学习6小时。
考试题型：名词解释、简答、材料题。
请先读取我提供的老师PDF，建立课程知识地图，生成三天冲刺计划，并立即开始Day 1的教学和闭卷小测。
```

第二天继续：

```text
$three-day-zero-base-exam 继续Day 2。读取当前课程PROGRESS.md，先抽测昨天的薄弱知识，再开始今天的任务。
```

临时只剩 5 小时：

```text
$three-day-zero-base-exam 我只剩5小时，执行最后冲刺模式，按老师提供的范围和题型优先级处理，最后给我一页考前速记。
```

**资料说明：** 此仓库是方法和模板，不含各门课程的完整课件。使用前请上传或链接教师资料；没有资料时 Skill 应主动说明限制，不能编造“老师重点”“押题概率”或考试答案。

## 为什么有用

1. **不是泛泛总结：** 先从课程文件建立“全书结构—教师证据—知识优先级”映射，再教学。
2. **零基础也能跟上：** 每个知识点先讲通俗的“为什么”，再提供考试可用的规范表述。
3. **不浪费三天：** 每个模块限定时间；未达标的内容记入清单，在剩余时间中优先补弱，不无限重学。
4. **能写题才算进步：** 按实际题型闭卷作答。材料题按“事实→理论→机制→结论”逐步搭脚手架。
5. **不造假掌握度：** 已看、已答、通过、未测、不会分开记录；错题与未回答题不能记为已掌握。

## 适配与声明

- `.agents/skills/` 是仓库内的 Skills 放置路径；是否自动发现、能否用 `$` 调用，取决于 Codex / Agent 环境的 Skill 支持与加载范围。
- 三天目标是**最大化有限时间内的考试准备度**，不是承诺通过考试，更不保证覆盖所有未知题目。
- 所有“重点”优先级有证据等级：教师明确提示、真题反复出现、课件结构推断。不能把 AI 自己的猜测冒充教师划定重点。
- 教师资料有含糊或疑错之处，要保留原文并说明不确定性；没有源文件绝不自称已核对。
