# 零基础选点、排序与时间预算

## 一、从课程材料建立考点库

先将所有已读取课件按“章节—知识点—题型适配—信息来源”组织。不能只读目录却声称已审阅全套。每个主题设置：

- 源文件、页码或章节范围。
- 知识类型：定义/分类、因果机制、理论比较、指标公式、材料应用。
- 证据等级：`E1` 教师明确范围或强调；`E2` 已给往年题、作业与课堂练习支持；`E3` 根据教材结构与考试题型推断。不得虚构教师预测、历年频率。
- 内容优先级：`A` 必读必练、`B` 应掌握、`C` 时间不足时可暂缓。
- 状态：`unread` / `read_unstudied` / `studied_pending_quiz` / `quiz_passed` / `application_pending` / `application_passed` / `remediation_needed` / `deferred_due_time`。

## 二、排序规则（按顺序比较）

1. 教师明确划定的考试范围、强调点（E1）。
2. 用户已经提供的真题、课堂作业、样卷覆盖（E2）；单独记题型及年份（若有），不得以一份卷子断言命中概率。
3. 本章其余内容的理论前置概念和贯穿多章的机制。
4. 与实际题型能匹配的定义、分类、理论机制、比较和计算内容。
5. 课件分量与关键概念密度（E3，标注推断）。

不要用“看着很热门”代替依据，也不要把每个主题都标为A。

## 三、时间预算

设用户可用有效学习时间为 `H` 小时：

- `H≤6h`：约15%扫范围/地图、40%高价值知识、25%答题、20%补弱与速记。
- `6<H≤12h`：约15%范围/地图、40%知识、25%题型迁移、20%模考与补弱。
- `H≈18h`：按 `three-day-plan.md` 的三天日内时间表。
- `H>18h`：额外时间优先用于更广覆盖与再测，不是重复讲已掌握内容。

一章很长时按知识模块分时，优先保证全书地图与重点考试题型，不要求每章均匀分配时间。用户调整时长或学习进度后即时重新规划。

## 四、有限时间内的“达标”语义

- 模块知识测≥8/10 → `quiz_passed`，不自动意味着会做材料题。
- 材料应用题≥16/20（如未另订标准）→ `application_passed`。
- 未答题得0分；若未提交整份题，标`未完成/尚未检验`，不是已错全部理论。
- 当前资料已阅读但未训练→`studied_pending_quiz`；刻意没学→`deferred_due_time`。
- 终期汇报采用**真实覆盖率**（例如A类已学习8/10，A类已测6/10，材料题通过1/3），不可给虚构掌握率百分比。
