# 三天冲刺执行计划（6小时/天基准）

## 基本原则

- “三天”指用户还有约三天学习机会。每天六小时是**有效专注学习时间**，不包括吃饭、睡觉和休息。不要压缩睡眠换取表面学习时间。
- 先全书地图，后重要概念，最后真题型输出。任何阶段都要有用户独立作答，不是AI单向长篇讲课。
- 不需要看完100%内容才测；更不把内容展示完等同于用户掌握。

## Day 1：从零到懂（360分钟）

| 时间盒 | 任务 | 完成判据 |
|---:|---|---|
| 30分钟 | 读取范围与资料，建立章节目录、证据登记，规划学习预算 | 明确源文件、未读取范围、题型 |
| 45分钟 | 全书结构地图，先解释课程研究的根问题和章际联系 | 学生能回答“这一章在研究什么” |
| 180分钟 | 最高优先级A类基础概念/前置理论：按模块概念→机制→课堂口径→小测 | 每个已覆盖模块有实际测试或未测标记 |
| 45分钟 | 名词解释速记与易混辨析，先从零解释再闭卷复述 | 记忆卡片及错误清单 |
| 60分钟 | 10分知识测试、即时批改、下一日安排 | 真正评分且列未学未测项目 |

## Day 2：从懂到会答（360分钟）

| 时间盒 | 任务 | 完成判据 |
|---:|---|---|
| 30分钟 | 间隔回忆Day1错误与A类知识 | 不看笔记作答 |
| 150分钟 | 补齐高优先级A/B主题，简答/论述按得分点练习 | 每题有作答、评分、纠错 |
| 60分钟 | 章节间因果与比较关系：同义、区别、机制链 | 至少2条确有来源的跨章连接 |
| 90分钟 | 材料题阶梯：标事实→选理论→讲机制→给判断，新题独立作答 | 至少一组有独立答案 |
| 30分钟 | 章测与错题状态更新 | 记录需要Day3回收的知识 |

## Day 3：从会答到会考（360分钟）

| 时间盒 | 任务 | 完成判据 |
|---:|---|---|
| 45分钟 | 错题主动提取、关键定义复述 | 找出分数损失最大的考点 |
| 105分钟 | 根据真实题型权重限时模拟；未给权重时明确“暂定” | 一份完成或明确标为未完成的试卷 |
| 60分钟 | 严格阅卷、错因与答题逻辑核查 | 透明分数和错误分类 |
| 105分钟 | 只修复高损失错点；用**新题**验证，不抄原参考答案 | 查漏补缺表与再次验收 |
| 45分钟 | 一页考前速记、时间分配与答题注意点 | 可快速复述关键词和答题框架 |

## 只剩不足3天

- **总学习时间≤6小时：** 20分钟建立范围/题型地图；2小时A类核心；1小时标准答题骨架；1.5小时限时典型题；1小时补弱/考前一页。时间可按实际情况调整。不要假装能覆盖全部内容。
- **6—12小时：** Day 1/2主题压缩为1次集中学习，保留至少20%的时间做真实题型输出，最后20%用于模拟与错题。
- **超过18小时：** 先加深A/B掌握，再系统补C类，不要一味堆更多模拟题。

## 学习过程中的控制信号

- 用户反复“看懂了但写不出来”：立即减少讲授，增加无提示回忆与关键词框架。
- 用户提出“市场结构咋分析”：先给一条真实材料事实→理论→机制示范，再给新题独立复述。
- 连续答错：短补弱一次，仍不通过标记后转下一模块，Day3回收。
- 用户指出时间改变：马上重排剩余模块，不重启日计划。
