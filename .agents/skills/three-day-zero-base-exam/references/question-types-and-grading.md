# 实际考试题型的命题与批改

## 总原则

- 题型以用户提供的实际考试为准；名词解释、简答题、材料题只是常用默认，不强制不相关题型。
- 来源限教师资料，所有评分点与该资料一致。课件未展开时不凭外部知识添加扣分点。
- 先出题、明确分值与时间，再让用户**独立闭卷**作答；用户明确要答案时再给，用户要求先答时严禁泄露。
- 评分必须逐题加总：原分值、得分、命中点、关键遗漏、最简规范答案、来源与补弱动作。等价正确表达得分；错别字不影响含义不扣分。
- 空白、无关占位（“1”）、问“咋分析”而未答，记0分且标**未作答**，而不是断言没有相关知识。

## 名词解释

**题干：** 尽量用课件明确出现的专业概念。**答法：** 所属/对象＋关键限定＋核心含义。零基础先用浅白话解释，再要求用户用教师可认可的正式术语独立写一遍。

4分例（仅为通用评分结构，非特定课程标准）：对象1、核心定义2、限制条件1。真实分值以题目为准。

## 简答题

**答法：** 总句提出理论观点＋分点列分类/因素＋每点说明机制＋必要的边界。若题干仅问“列出五项”，不因为没讲应用案例扣分。

## 论述题

**答法：** 清楚定义→理论机制→分层论证→比较/条件→结论。不得使用空泛背景、无关词语凑字数。跨章材料必须可以追溯各自来源。

## 材料题四段法

1. **材料事实：** 在题干中找可验证的现象、数据、行动。
2. **对应理论：** 在已读课件中选择真正匹配的概念。
3. **作用机制：** 说明为何从事实推到理论结果；必要时计算指标。
4. **结论/政策：** 给出在证据范围内成立的判断或措施，不无依据断言。

教师常见20分综合题可按**理论30% / 事实25% / 机制30% / 结论15%**辅助批改；实际小题分值优先。材料未给够，写“无法认定”，比如高集中度不直接推违法垄断、跟随调价不能直接推明确卡特尔。

## 材料题三级脚手架

- **一级（示范）：** 教师给短材料，Agent示范一条事实→理论→机制；其他事实让学生找。
- **二级（半独立）：** 只标出章节范围，不给具体知识名，让学生自己组织。
- **三级（独立）：** 换一个新案例，不给任何提示，按满分要求阅卷；通过才记应用掌握。

## 模考

- 在 Day 3 用教师已知的题型、题量、分值、时间生成模拟卷。未知的条件先标明暂定（如总分100分、90分钟只是模拟假设）。
- **题目生成后不展示答案/评分细则全文**，防止影响闭卷；可展示每题分值。
- 如用户未完整作答，则如实按已交内容评分并标`未完成`，不能把未参与当作完成试卷后的真实能力评估。
- 评分后挑选最高损失的2–4个问题训练，新题检测迁移；不要用刚公布答案的原题当再次掌握证明。
