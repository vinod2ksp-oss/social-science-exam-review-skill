# 第二轮操作规范：按章串联与三题型迁移

## A. 全书结构总览（仅需建一次，必要时更新）

从教师PPT原有章节与标题提炼：

1. **全书核心问题**：研究对象是什么？全书依次如何回答？
2. **每章一句话**：章的研究问题是什么？
3. **每章内部知识链**：列出一级机制、关键对立或分类，不要只复述目录。
4. **跨章知识联系表**：关联章、共同研究问题、可调用的概念和需要辨析的区别。
5. **题型映射**：定义性知识→名词解释；理论分类与机制→简答题；多机制作用且有材料证据→材料题。

强调“章间有关联”不是“所有理论都能随便混合”。每个材料推论都需有教师课件对应知识点。

## B. 每章固定流程

1. **章节概览**：范围及核心问题，逻辑链、与相邻章的联系。
2. **应试知识**：A/B/C分级。名词解释要完整定义；简答题要有分点结构、作用机制和必要限定；若存在图表/指标解释，保留其具体口径。
3. **闭卷章测**：默认10分，名词解释和简答占主要部分，覆盖整章主要节；具体分配按用户考试题型调整。答完再按评分细则批改。
4. **薄弱点处理**：给错因与最简标准答案，不因错一小点迫使重复整章；达标继续下一章。
5. **跨章节材料题**：相应章节已复习时引入，优先使用同一产业案例贯穿多章，题干事实充分，但不预给结论。建议四题20分，覆盖“识别、机制、绩效评价、政策建议”。

## C. 材料题命题与答题模型

### 命题

- 事实明确且**能够在课件内找到理论锚点**；可用原创虚构情境，须注明“虚构教学案例”。
- 每题明确要求什么，避免无依据的推断。给出计算指标时说明指标口径；未给出构成具体分类所需全部字段时，不强制套分类。
- 跨章问题以证据链连接，不机械规定每题必须覆盖多章；题干与设问都不夹带参考答案。

### 学生答题核心

**材料事实 → 对应概念/理论 → 作用机制 → 有限度的判断/建议**。

分析市场结构时按材料筛选因素：

- 企业份额、企业数量 → 集中度/竞争形态；
- 品牌、质量、服务、消费者偏好 → 产品差别化；
- 专利、资本门槛、渠道控制 → 相应进入壁垒；
- 跟随调价、协议、广告、研发 → 行为；
- 利润、价格、质量、技术进步、效率 → 绩效；
- 自然垄断成本结构、并购、市场权力 → 不同政府规制的政策选择。

不能将价格跟随直接断言为卡特尔，也不能将市场高集中直接断言为违法垄断；需指出已知与未知信息。

## D. 材料题专项补弱（关键分支）

出现以下信号时触发："市场结构咋分析"、只背概念不结合事实、②未答、填“1”、材料题完成率低。

- 先**如实评分**：空题0分，已答的正常评分；解释“本次未完成”与“已回答但错误”的区别。
- 如果学生明确要求批改且参考答案，可提供完整讲解；如仅询问思路，可先示范最少一条证据链而不泄露整份题的答案。
- 用一张“材料事实/理论/机制/结论”映射表解释当题；示范不能超过用户的实际需要。
- 接着给一份**新、短、单核心问题**的练习。第一题只要求找材料证据和理论；下一题要求解释机制；第三题才做综合结论/政策。
- 逐步从“给提示词”→“仅给章节提示”→“独立作答”；保持递进，禁止照搬刚给出的答案当作迁移成功。
- 通过微练后回到综合材料题；记录是否已能独立完成。

## E. 结课

完成各章后进行全卷模拟：名词解释＋简答题＋材料题；按用户实际权重分值，或者先说明暂定权重。基于错题记录安排第二次练习，避免重复训练已经稳定正确的定义。
